# RSS/Atom feeds watched by the "RSS watch" workflow
# (.github/workflows/rss-watch.yml) and by `node tools/rss-watch.js`.
#
# One feed URL per line; lines starting with # are ignored. When new items
# appear, the watcher triggers the Scrape workflow (needs the WATCH_PAT
# secret — see docs/AUTOMATION.md).
#
# No feeds are enabled by default: only add URLs you verified in a browser
# (you should see XML or your reader's feed view). To find a portal's feed,
# look for an RSS link in its footer or try appending /feed/ on
# WordPress-based portals.
#
# Example (uncomment after verifying):
# https://example-portal.test/feed
